# ТАУ — теория автоматизированного управления

Формально ДЗ пока не выдаётся — вся работа выполняется на парах.

Тема работы: построение математической модели и автоматическое управление оборотами
вентилятора ПК (обычный 4-контактный вентилятор с тахометрическим выходом).

## Работы

| Работа | Описание | Статус |
|--------|----------|--------|
| Мат. модель вентилятора ПК | Моделирование регулировки оборотов вентилятора ПК: схемы VisSim, экспериментальные данные, код для Arduino | 🔨 В работе (на парах) |

## О чём работа

Цепочка регулирования: задание оборотов → управляющее воздействие (ШИМ, 0–255) → вентилятор →
фактические обороты (тахо-импульсы) → обратная связь.

- **Статические испытания** — `Вентилятор.xlsx`, зависимость «ШИМ → скорость»:
  экспериментальная кривая ШИМ 0–250 → 0–2280 об/мин; рабочая (линейная) зона — ШИМ 30–250 →
  275–2280 об/мин (рабочая точка — (30; 275)). Рядом «модельные» столбцы как отклонения от
  рабочей точки (`ШИМ−30`, `Скорость−275`). Отсюда статический коэффициент передачи; в коде
  уставка пересчитывается в ШИМ обратным коэффициентом: `pwm = set_obr / 9.8895`.
- **Динамические испытания** — `vent.txt`: лог переходного процесса с терминала, три колонки
  «pwm, обороты, set_obr» — ступенька ШИМ 0 → 150, разгон с ~0 до ~1545 об/мин при задании 2280.
- **Модель объекта** — по переходному процессу объект аппроксимирован звеном второго порядка
  (критически демпфированным): коэффициент передачи `K ≈ 10.25`, постоянная времени `T ≈ 0.58 с`.
  Модель проверяется наложением на эксперимент.
- **Схемы VisSim** (`2) Схемы VisSim/`) — логические схемы для построения математической модели
  автоматизированного управления вентилятором (в данном случае).
- **Управление на реальном объекте** — Arduino: читает тахо-импульсы (внешнее прерывание на
  пине 2), выдаёт ШИМ (пин 3), скорость сглаживает медианным фильтром (окно 3), режим и уставка
  задаются командами по UART (9600 бод).

## Команды терминала (UART, 9600 бод)

| Команда | Действие |
|---------|----------|
| `pwm<N>` | напрямую задать ШИМ (в отклонении от `pwm_min = 30`), допустимо −5…220 |
| `set<N>` | задать уставку оборотов (только в `copy_vent`) |
| `out<N>` | период вывода данных, 10…2000 мс; `out0` — включить/выключить вывод |
| `imp<N>` | число тахо-импульсов на измерение, 10…100 |
| `sta` | статический режим: `T_out = 1000` мс, `n_imp = 10` |
| `din` | динамический режим: `T_out = 100` мс, `n_imp = 1` |

## Файлы

Файлы в репозитории:

- `1) Ардуино код/Вентилятор/`
  - `vent_calc_1/vent_calc_1.ino` — управление: ШИМ на пине 3, тахо на пине 2 (прерывание 0,
    `RISING`, `INPUT_PULLUP`), медианный фильтр, терминал по UART; вывод «pwm обороты» каждые
    `T_out` мс; команды `pwm`, `out`, `imp`, `sta`, `din`.
  - `copy_vent/copy_vent.ino` — то же + команда `set` (уставка) с линейной связью
    `pwm = set_obr / 9.8895`; вывод «pwm обороты set_obr».
- `2) Схемы VisSim/Вентилятор/` — `Исходная.vsm`, `Полудоработанная.vsm`, `П-регулятор(готов).vsm`
  (логические схемы мат. модели; файлы в текстовом формате VisSim).
- `3) таблицы и текстовые файлы/Вентилятор/` — `Вентилятор.xlsx` (статика: ШИМ → скорость),
  `vent.txt` (лог переходного процесса: pwm, обороты, set_obr).
- `VisSim30/` — программа моделирования VisSim: `Vissim32.exe`, `analyz32.dll`, `vsmrt32.dll`.
