## О чём работа (по коду и схемам)

Объект управления — обычный 4-контактный вентилятор ПК с тахометрическим выходом.
Цепочка регулирования: задание оборотов → управляющее воздействие (PWM, 0–255) →
вентилятор → фактические обороты (тахо-импульсы) → обратная связь.

- **Статические испытания:** `Вентилятор.xlsx` — две кривые «Шим → Скорость»:
  экспериментальная (ШИМ 0–250 → 0–2280 об/мин, почти линейный участок) и «Модель статики»
  (аналитическая аппроксимация этой зависимости). Отсюда статический коэффициент передачи,
  который далее используется для оценки управляющего воздействия (`copy_vent.ino`, команда
  `set`: `pwm = set_obr / 9.8895`).
- **Динамические испытания (переходной процесс):** `vent.txt` — лог с терминала
  «pwm, обороты, set_obr»: ступенька ШИМ 0 → 150, разгон вентилятора с ~0 до ~1545 об/мин
  (при setpoint 2280). По этой кривой определяются динамические параметры модели
  (постоянная времени, задержка).
- **Модель и регулятор:** три схемы VisSim — `Исходная` (объект без регулятора),
  `Полудоработанная` (промежуточная версия), `П-регулятор(готов)` — замкнутая система
  с пропорциональным регулятором, проверка переходного процесса в модели.
- **Управление на реальном объекте:** Arduino читает тахо-импульсы (внешнее прерывание,
  медианный фильтр от выбросов), выдаёт PWM, термиалом по UART задаются режимы и setpoint.
  Скорость передачи 9600, вывод «pwm обороты» каждые 100–1000 мс — данные для сверки
  модели с реальностью.
- **Инструмент:** VisSim30 (см. папку `VisSim30/`) — редактор схем и симулятор.

Связь с ТАУ: типовая задача построения мат. модели объекта и синтеза П-регулятора
для системы с обратной связью, дальше — исследование качества регулирования
(перерегулирование, время установления) в модели и на стенде.

Файлы выполненной работы лежат здесь же, структура повторяет флешку
`E:\Учеба(ИЖГТУ)\4) Учеба (2026-2027)\ТАУ`:

- `1) Ардуино код/Вентилятор/`
  - `vent_calc_1/vent_calc_1.ino` — управление вентилятором: PWM на пине 3, тахо-сигнал на пине 2 (прерывание), медианный фильтр, терминал по UART (9600) с командами `pwm`, `out`, `imp`, `sta`, `din`; вывод «pwm обороты» с периодом `T_out`
  - `copy_vent/copy_vent.ino` — то же + команда `set` (задание оборотов), линейная связь `pwm = set_obr / 9.8895`
- `2) Схемы VisSim/Вентилятор/` — `Исходная.vsm`, `Полудоработанная.vsm`, `П-регулятор(готов).vsm`
- `3) таблицы и текстовые файлы/Вентилятор/` — `Вентилятор.xlsx`, `vent.txt` (лог эксперимента: PWM, время, обороты; разгон до ~2280 об/мин)
- `VisSim30/` — программа моделирования: `Vissim32.exe`, `analyz32.dll`, `vsmrt32.dll`
