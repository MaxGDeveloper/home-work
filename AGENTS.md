## Окружение

- Windows, git уже настроен (MaxDev), ветка `master`.
- Remote: `origin` = https://github.com/MaxGDeveloper/home-work.git — **приватный** репозиторий,
  опубликован 07.10.2026. Аккаунт GitHub: MaxGDeveloper, креды хранит Git Credential Manager
  (scope `repo` — можно пушить и управлять репозиторием через REST API). `gh` CLI не установлен.
  Ветка по умолчанию — `master` (переключена вручную, т.к. GitHub создаёт `main`).
- Консоль PowerShell выдаёт кракозябры при выводе кириллицы (cp866 vs UTF-8) — для проверки имён файлов/папок использовать чтение каталога, а не вывод shell.
- **Кодировка в HTTP-запросах:** PowerShell 5.1 (`Invoke-RestMethod`) кодирует строковый
  `-Body` как Latin-1, и вся кириллица уходит в GitHub как `?` (была битая описания
  репозитория — исправлено 07.10.2026). Для JSON с русским текстом тело собирать явно:
  `$bytes = [Text.Encoding]::UTF8.GetBytes($json)` и передавать `$bytes` с
  `-ContentType 'application/json'`.
- Пустие папки git не отслеживает: закоммитятся сами, когда внутри появятся файлы.
- Предупреждение `LF will be replaced by CRLF` — норма, игнорировать.
