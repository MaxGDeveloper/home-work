# AGENTS.md

Заметки для агента. Цель репозитория: отслеживание имеющегося ДЗ и прогресса его выполнения. Файл дополняется по ходу дела — не переписывать вслепую, сохранять накопленный контекст.

## Контекст

- Специальность: Информатика и вычислительная техника, 4 курс.
- Предметы (папки уже созданы): Микропроцессорные системы, ТАУ, Системы искусственного интеллекта, Безопасность жизнедеятельности, Программирование 1С, Основы системного анализа, Тестирование программного обеспечения + отдельная папка ВКР.
- `README.md` — список предметов; прогресс пока не заполнен, ждём данные о ДЗ от пользователя.
- Информация о ДЗ и ВКР ещё не собрана — не выдумывать задания и статусы, только то, что скажет пользователь.

## Основные правила

- Пользователь просит не придумывать: при неясности — спросить через `question`.
- Все решения по структуре и формату трекера договариваемся заранее (последнее: папки по предметам + README, ВКР — отдельный раздел).

## Окружение

- Windows, git уже настроен (MaxDev), ветка `master`.
- Консоль PowerShell выдаёт кракозябры при выводе кириллицы (cp866 vs UTF-8) — для проверки имён файлов/папок использовать чтение каталога, а не вывод shell.
- Пустие папки git не отслеживает: закоммитятся сами, когда внутри появятся файлы.
- Предупреждение `LF will be replaced by CRLF` — норма, игнорировать.
