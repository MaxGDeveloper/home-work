## Описание заданий 4–7 (из файлов на Яндекс.Диске)

### 4. Инструмент POSTMAN
Пройти курс по ссылке: https://stepik.org/join-class/2cca1f3ecbb4324d585fec9137d7d946a5d9dbe2
После прохождения написать на почту (должны получить сертификат).

### 5. POSTMAN запросы
Используя POSTMAN, написать POST/GET запросы к итоговой работе по предмету «Интернет программирование».
Если работы нет или не получается по другим причинам — запросы к любому сайту в сети интернет.
Предоставить файл с телом запроса и полученным ответом. Файл отправить на почту.

### 6. UNIT тестирование
Покрыть тестами полученный программный код (архив `StoreJSON.zip` в папке заданий на Диске).
Запустить тесты и проанализировать результаты.
Папку решения (приложение/библиотека классов + проект с тестами) выслать на почту в виде архива *.zip.

### 7. Разработка через тестирование (TDD)
Получить ТЗ (функциональные требования) и создать автоматизированные тесты. Запустить тесты
(обязательно должны провалиться), затем написать функциональность для их прохождения.
Рекомендуется Windows Forms (.NET Framework 4.7+), фреймворки NUnit / xUnit / MS Test.

ТЗ — «Система просмотра товаров на складе»:
- заполнение данных о товарах: наименование, количество, единицы измерения, текстовое описание;
- просмотр данных в формате таблицы;
- доступ через форму авторизации; при неверных данных — сообщение, после трёх неудачных попыток — сообщение с контактами техподдержки и сисадмина (телефон и почта);
- хранение данных: JSON/XML файлы или MS SQL Server / MySQL / Entity Framework; база или файлы добавляются в проект.

Сдать: решение с проектом Windows Forms и проектом тестов, архив *.zip на почту.
