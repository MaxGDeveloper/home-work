## Задание 1 (подробно)

Страница задания в СЭО: https://ee.istu.ru/mod/assign/view.php?id=51842
(раздел «Неделя 1-2. Лабораторная работа. Обзор программных пакетов моделирования ИИ»).

**Цель:** знакомство с программными пакетами моделирования искусственного интеллекта (ИИ).

**Что сделать:**
- выбрать **1 и более сложную** и **2 и более простую** программу;
- изучить основной подход к решению задач ИИ, реализованный в каждом выбранном пакете;
- рассмотреть один из примеров, поставляемый с программой.

Допускается выполнение в малых группах (2 студента).

**Как сдать:** приложить к заданию в СЭО отчёт по лабораторной работе в виде файла.
Отчёт должен содержать краткие сведения теории соответствующего направления ИИ
и пример решения задачи по каждой программе.
