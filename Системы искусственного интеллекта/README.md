## Задание 1-2. Обзор программ моделирования ИИ

Страница задания: https://ee.istu.ru/mod/assign/view.php?id=51842

**Цель:** знакомство с программными пакетами моделирования искусственного интеллекта (ИИ).

**Что сделать:**
- выбрать **1 и более сложную** и **2 и более простую** программу;
- изучить основной подход к решению задач ИИ, реализованный в каждом выбранном пакете;

## Задание 5-6. Экспертные системы

Страница задания: https://ee.istu.ru/mod/assign/view.php?id=163093

**Изучить материалы** (Джордж Ф. Люгер «Искусственный интеллект. Стратегии и методы решения
сложных проблем»):
- раздел 5.3 «Продукционные системы» (стр. 196–211);
- разделы 7.0–7.3 «Экспертные системы» (стр. 273–306).

**Выполнить:** разработку простой экспертной системы, содержащей:
- 3 и более правила;
- 3 и более шаблона фактов;
- 3 и более факта для каждого шаблона.

При запуске машины логического вывода должно выполняться срабатывание 3 и более правил
и добавление/изменение/удаление 3 и более фактов в рабочей памяти экспертной системы.

**Как сдать:** отчёт в виде файла.

## Задание 9-10. Построение деревьев решений

Страницы заданий: https://ee.istu.ru/mod/assign/view.php?id=14764 (часть 1),
https://ee.istu.ru/mod/assign/view.php?id=51836 (часть 2).
*Объём: нужна одна или обе части — уточняется.*

**Часть 9-10 1. Изучение алгоритма построения дерева решений ID3**
- Изучить: Люгер, глава 9.3 «Индуктивный алгоритм построения дерева решений» (стр. 392–399).
- Построить 2 и более уровней дерева решений на основе эвристики остаточной информативности
  по алгоритму ID3. Данные для анализа — самостоятельно.
- Выполнить на ЯВУ, в MS Excel / LibreOffice Calc или на бумаге. Приложить результат файлом.

**Часть 9-10 2. Изучение алгоритма построения дерева решений J48 в ПО «Weka»**
- Построить дерево решений алгоритмом J48 в ПО «Weka». Данные — самостоятельно.
- Приложить результат выполнения в Weka в виде файла.
- Примечание: после загрузки данных (например, файла `Iris.arff`) указать атрибут
  категории/класса («class»).

## Задание 11-12. Нечеткий логический вывод

Страницы заданий: https://ee.istu.ru/mod/assign/view.php?id=29233 (часть 1),
https://ee.istu.ru/mod/assign/view.php?id=29252 (часть 2).
*Объём: нужна одна или обе части — уточняется.*

**Изучить материалы:**
1. В. В. Круглов, М. И. Дли, Р. Ю. Голунов «Нечеткая логика и искусственные нейронные сети»,
   глава 1 «Нечеткая информация и выводы» (стр. 3–40).
2. Яхъяева Г. Э. «Нечеткие множества и нейронные сети» (материал для самостоятельной работы,
   стр. 10–151).
3. Тэрано Т., Асаи К., Сугэно М. «Прикладные нечёткие системы» (материал для
   самостоятельной работы).

**Часть 11-12 1.** Выполнить практическую реализацию примера решения задачи нечеткого
логического вывода. Выполнить на ЯВУ, в MS Excel / LibreOffice Calc или на бумаге.
Задача выбирается самостоятельно. Приложить результат файлом.

**Часть 11-12 2.** Выполнить практическую реализацию примера решения задачи нечеткого
логического вывода, используя ПО «FisPro» или «FuzzyLite» (или другое). Задача выбирается
самостоятельно. Приложить результат выполнения в ПО в виде файла.

**Примечание (для обеих частей):** задача должна иметь сложность не менее: **2 входных
переменных, 3 правила логического вывода, 1 выходная переменная**.

## Задание 15-16. Генетический алгоритм

Страница задания: https://ee.istu.ru/mod/assign/view.php?id=162260

**Изучить материалы:**
1. А. В. Коробейников «Программирование нейронных сетей» (стр. 23–27).
2. Джордж Ф. Люгер, глава 11 «Машинное обучение на основе социальных и эмерджентных
   принципов» (стр. 483–517).
3. «Генетический алгоритм» (machinelearning.ru).
4. Т. В. Панченко «Генетические алгоритмы», 2007 (материал для самостоятельной работы).

**Выполнить:** изучение практического примера решения задач с использованием генетического
алгоритма — одно из заданий лабораторной работы №1 «Персептроны» (Коробейников, стр. 28–32),
применив генетические алгоритмы для обучения персептрона.

Альтернатива: предложить свою задачу и решить её с помощью генетического алгоритма
(например, аппроксимация функции аналогично методу наименьших квадратов).

Выполнить на ЯВУ. Приложить результат в виде файла.
