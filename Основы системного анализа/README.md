# Основы системного анализа

Дисциплина «Основы системного анализа» (4 курс).

По плану — **5 лабораторных работ**, из которых в итоге формируется **курсовая работа**
(см. раздел [Курсовая работа](../Курсовая%20работа/README.md)).

**Лабораторные = первые 5 практических занятий** из методички Силич
(см. раздел [Материалы](#материалы-в-распоряжении)): ПЗ 6 «Разработка информационного
обеспечения» **не выполняется** (подтверждено пользователем 19.10.2026).

По методичке форма контроля каждого ПЗ — рукописный отчёт; все занятия делаются на одном
объекте — сложной проблеме, выбранной как индивидуальное задание (выбирается/согласуется
с преподавателем до первого ПЗ; варианты — в приложении методички).
