# Курсовая работа — системный анализ

> Курсовая работа по дисциплине **«Основы системного анализа»** (4 курс).
> Отдельный раздел трекера, так как работа глобальная (формируется из 5 лабораторных работ).

## Тема

**«Системный анализ процесса учёта и исполнения планов работ на предприятии
"АО Воткинский завод"»**

- Объект исследования: предприятие АО «Воткинский завод».
- Предмет исследования (процесс): учёт и исполнение планов работ.

## Статус

⬜ В планах. Детали (метод оценивания альтернатив, требования к оформлению в ИжГТУ,
список источников) — уточняются.

## Как формируется

Курсовая работа собирается из **5 лабораторных работ** по «Основам системного анализа»
(темы лаб. пока неизвестны, см. [README предмета](../Основы%20системного%20анализа/README.md)):
этапы лабораторных работ в совокупности и составляют содержательную часть курсовой.

## Что уже известно (по методичке ТУСУР, справочно)

**Структура пояснительной записки:**
- титульный лист; задание; оглавление;
- введение (объект и предмет исследования, актуальность, цель и задачи; объём 1–2 стр.);
- раздел 1 «Краткое описание объекта исследования»;
- раздел 2 «Моделирование системы»:
  - 2.1 модель взаимосвязи системы с окружающей средой (модель «чёрного ящика»
    + структура надсистемы, стейкхолдеры/акторы);
  - 2.2 модель состава и структуры системы;
  - 2.3 построение дерева причин;
- раздел 3 «Постановка целей и поиск решений»:
  - 3.1 построение дерева целей;
  - 3.2 оценка целей методом анализа иерархий (МАИ);
- раздел 4 «Разработка и оценка альтернатив решения проблемы заданным методом»
  (название метода конкретизируется; разработка альтернатив → описание метода →
  оценивание и выбор);
- раздел 5 «Разработка программного продукта, реализующего заданный метод
  оценивания/сравнения альтернатив» (алгоритм → описание программы → тестирование);
- заключение; список использованных источников (не менее 15);
- приложения (обязательные: дерево целей + результаты оценивания; алгоритм программы).

**Этапы работы в целом:** описание объекта → базовые модели системы → дерево причин →
дерево целей → оценка целей (МАИ) → альтернативы достижения приоритетной цели →
оценивание/выбор альтернатив заданным методом → разработка ПО для выбора наилучшего
способа решения проблемы → защита (устный доклад + демонстрация программы).

**Методы оценивания/сравнения альтернатив** (из методички, назначается преподавателем,
набор базовый: нечёткое оценивание на различных функциях принадлежности, групповое
ранжирование, парные сравнения (в т.ч. Саати), метод Черчмена–Акоффа, множество Парето,
аддитивная/мультипликативная свёртка критериев, «идеальная точка», критерии среднего
выигрыша, Лапласа, Вальда, максимакса, Гурвица, Сэвиджа и др.).

## Открытые вопросы

- Список и темы 5 лабораторных работ;
- конкретный метод оценивания/сравнения альтернатив для КР (задаёт преподаватель);
- требования ИжГТУ к оформлению (методичка выше — ТУСУР, 2022);
- нужно ли согласовывать тему с преподавателем и как.
