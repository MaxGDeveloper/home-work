## О лабораторной

Тема — **пневматическая логика**: логические элементы, собранные на сжатом воздухе и трубках
(без электроники).

Задание:

- даны **4 пневматические схемы**, по ним нужно определить, какой логический элемент
  реализован — **И**, **ИЛИ**, **триггер**, **генератор** (каждая схема — один из этих
  четырёх элементов);
- для каждой схемы: **нарисовать саму схему** и составить **таблицу истинности**.

Работа не сдана — её нужно доделать. Материалов (фото схем, методички) в репозитории нет;
если появятся — добавить в этот раздел.
